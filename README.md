# Copy-paltergeist

Статический лендинг-клон для Poltergeist.

## Как запускать локально

Я выбрал **Python-сервер** как базовый вариант, потому что он:
- уже есть почти в любом окружении;
- не требует установки зависимостей;
- идеально подходит для отдачи одного `index.html`.

### Быстрый запуск

```bash
python3 serve.py
```

После запуска открой:
- `http://127.0.0.1:8000`

### Настройка хоста/порта

```bash
python3 serve.py --host 0.0.0.0 --port 8080
```

## Альтернатива

Если нужен только максимально короткий запуск без скрипта:

```bash
python3 -m http.server 8000
```
